# 💫 About Me:
Ao longo da minha experiência, venho atuando de forma ativa no desenvolvimento de soluções Backend em aplicações cloud-native, com foco em Java, Spring Boot, AWS e práticas de DevOps, aplicando arquitetura de microsserviços e integrações por mensageria para garantir escalabilidade, performance e resiliência.<br><br>Também contribuo para o desenvolvimento de componentes de framework (bibliotecas e aceleradores), criando soluções reutilizáveis que aceleram a entrega e aumentam a padronização entre diferentes times.<br><br>No dia a dia, participo de todo o ciclo de desenvolvimento de software, desde o planejamento e definição técnica, passando pela implementação de funcionalidades, revisões de código, até a implantação em produção.<br><br>Tenho atuado no apoio à implementação e manutenção de pipelines de CI/CD, fortalecendo práticas de automação e integração contínua para aumentar a qualidade e a eficiência do processo de entrega.<br><br>Busco sempre alinhar as soluções aos requisitos técnicos e de negócio, garantindo a qualidade do software por meio de testes automatizados e boas práticas de engenharia.
